# Learned Recipes

This file is the compact index for MDF learned recipes. Detailed recipe bodies live in `docs/ai-harness/recipes/*.md` so operational memory stays searchable without turning this index into a long runbook.

Search both locations before Unity CLI, build, screenshot, Photon, or multiplayer automation work:

```bash
rg -n "<topic keywords>" docs/ai-harness/learned-recipes.md docs/ai-harness/recipes .agents/skills tools/harness
```

## Recipe Lifecycle

Use `docs/ai-harness/recipe-lifecycle.md` for required metadata, stale review, archive rules, and the `touch_recipe.py` / `scan_stale_recipes.py` helpers. Do not update `Last verified` without command, test, or artifact evidence.

Batch recipe touches near the end of planning or verification instead of before every minor read command. Keep `Last used` and `Last verified` accurate, but do not add lifecycle churn for low-signal `rg` or `Get-Content` checks.

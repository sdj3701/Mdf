# Learned Recipe Files

Use this directory for detailed recipes that are too long for `docs/ai-harness/learned-recipes.md`.

New recipes should follow `docs/ai-harness/recipe-lifecycle.md`, include the required metadata block, and live as separate files in this directory. `tools/harness/recipes/touch_recipe.py` creates new recipe files here when an id does not already exist.

Keep `learned-recipes.md` as a compact index. Refresh or add a one-line pointer there when a new recipe needs to be highly visible.

Archive reviewed historical recipes under `archive/`. Put deprecated but still referenced recipes under `deprecated/` when a separate file makes the replacement path clearer.
